The scottyledell.us arc — what happened

  • Goal: publish the doculink on the branded scottyledell.us (LBKdotdev can't push to joeycastillo.us).
  • First wrong turn: called it "blocked on a token." Wrong — the deploy bridge holds a real CF token server-side.
  • Second wrong turn: theorized a rogue _worker.js catch-all. Wrong — a 308 on /index.html proved native Cloudflare Pages, no worker.
  • Real root cause found (pair-verified): a prior single-file homepage deploy atomically replaced the whole Pages snapshot, wiping /s/*, /metal/*, /proposal/*. With no 404.html, Pages natively serves the homepage for every miss — so the site is homepage-only.
  • Real bug fixed: the bridge caller-gate rejected every caller — the gate secret had a trailing newline (67 bytes vs 64). Trimmed it, restarted the bridge. Auth works now — this had silently blocked all scottyledell deploys.
  • Doculink minted as a proper Latchkey (s/01dd6aae-…/), deploy set assembled and navigator-approved.
  • Deploy POST authenticated, then Cloudflare returned 403 — the bridge's CF token lacks Pages:Edit on the account owning the scottyledell project. Deploys are atomic, so Scotty's live site is untouched.
